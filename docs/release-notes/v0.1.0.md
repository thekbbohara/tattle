# Tattle v0.1.0

First public release. One command reads your local Claude Code and Codex logs
and prints a receipt of what your agents did to your machine, ranked by risk,
each with a way to stop it next time. Offline, read-only, secrets masked.

## What it does

- Reads Claude Code logs (`~/.claude/projects`, or `$CLAUDE_CONFIG_DIR`) and
  Codex logs (`~/.codex/sessions`, or `$CODEX_HOME`), last 7 days by default
  (`--days N`, `--all`).
- Seven rules: `pipe_to_shell` (`curl | sh`), `force_push`, `delete`
  (`rm -rf`, `git reset --hard`, `git clean -f`, `find -delete`, ...), `sudo`,
  `outside_project` writes, `secret_access`, `install`. Shell lines are split
  into simple commands first, quote-aware.
- Every flag shows a fix: the Claude Code `permissions.deny` entry or the
  Codex `sandbox_mode` / `approval_policy` setting that blocks it next time.
- Terminal receipt, `--json` and a single-file `--html` report (no external
  fonts or scripts).
- `--min` severity filter, `--project` filter, `--home` override.
- Exit code 1 when a critical flag is found, so it can run in a hook or CI.
- `tattle demo DIR`: a fake home with a fixed fake week (9 sessions, 1,412
  commands, 2 critical, 10 high, 5 medium, 14 low) to try it safely.

## Privacy

- No network code, no telemetry. Three dependencies: `regex`, `serde`, `serde_json`.
- Never changes your logs. Never prints prompts, replies or tool output.
- Every command and path is masked with Keyleak's secret detector before
  output, in every format. This release adds JWT masking on top of Keyleak's
  detectors.

## Install

Linux x86_64 (static musl), macOS aarch64 and x86_64 binaries are attached
below, with `SHA256SUMS`. Or from source (Rust 1.80+):

```sh
cargo install --git https://github.com/thekbbohara/tattle --tag v0.1.0
```
